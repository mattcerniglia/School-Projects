**Notes for running these programs:**
- Weather-App needs your own OpenWeatherMap key. Replace `YOUR_OPENWEATHERMAP_API_KEY` in `weather_app.py`.
- Powerball looks for `tickets.txt` in your Downloads folder.
- File-Fun uses a hardcoded Windows path (`C:\Users\mattc\Documents\filefunnumbers.txt`).
- The GUI apps require `PyQt5`. Weather-App also requires `requests`, and Magic-Square requires `matplotlib` and `numpy`.
